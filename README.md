| 로그인      | 로그인         |                    | 1. 입력<br> 1-1 아이디와 비밀번호를 입력하게 한다.(입력받은 정보가 USERS 테이블에 있는지 확인)<br> 1-2 아이디와 비밀번호는 정규화에 맞게 입력 받을 수 있게 한다.<br> 2. 출력내용<br> 2-1 아이디와 비밀번호 입력창<br> 2-2 정규화 내용이 틀리다면 올바르지 않다고 출력하고 다시 입력 받게함<br> 2-3 로그인을 할때 관리자로 로그인을 하면 관리자 메뉴로 일반 회원이 로그인을 하면 일반회원 메뉴로 나오게 출력. | O      | O    |
| 계정찾기    |                |                    | 1. 아이디와 비밀번호를 기억하지 못할 시, 계정 찾기 탭으로 들어가 찾을 수 있다.<br> 1-1 계정 찾기는 회원가입을 할 때 입력하는 이메일을 입력 시 아이디와 비밀번호를 찾을 수 있도록 한다.<br> 2. 출력 내용<br> 2-1 계정찾기 탭<br> 2-2 계정 생성 시 입력 한 이메일을 입력하세요. |        |      |
| 회원가입    |                |                    | 1. 회원가입<br> 1-1 회원가입은 아이디, 비밀번호, 이름, 전화번호, 이메일, 주소를 입력 받는다. (이메일 인증을 받아야 회원가입이 가능!)<br> 2. 출력<br> 2-1 회원가입 선택을 하면 아이디, 비밀번호, 이름, 전화번호, 이메일, 주소를 차례대로 입력하게끔 출력.(정규화에 맞지 않으면 틀리다고 출력 후 다시 입력받는다) |        | O    |
| 회원관리    | 회원정보 조회   |                    | 1. 출력 내용<br> - 이름, 전화번호, 이메일, 주소                                                              | O      | O    |
|             | 관리자 회원 정보 조회 |                | 1. 출력 내용<br> - 모든 회원의 이름, 전화번호, 이메일, 주소                                               | O      |      |
|             | 관리자 회원 정보 수정 |                | 1. 관리자는 회원의 정보를 수정 가능하다.<br> 2. 관리자는 회원이 규정에 위배되는 활동을 할 시 모니터링 후 즉시 로그인 제제를 가할 수 있다. | O      |      |
| 마이페이지   | 내 정보 조회    |                    | 1. 출력 내용<br> - 개인정보(아이디, 이름, 전화번호, 이메일, 주소)<br> - 관리자는 모든회원의 개인정보를 조회 할 수 있다. | O      | O    |
|             | 회원 탈퇴      |                    | 1. 마이페이지에서 회원탈퇴 탭 이동<br> - 아이디, 비밀번호 재입력<br> - 정말로 삭제 할 것인지 다시한번 물음하고 삭제 처리<br> 2. 관리자는 모든 회원의 탈퇴 권한을 가진다. | O      | △ (일부기능 제외) |
|             | 내 정보 수정    |                    | 1. 수정 항목을 번호로 입력 받는다.<br> ex) 1. 비밀번호 2. 전화번호 3. 이메일 4. 주소<br> 1-1 입력받은 개인정보(비밀번호, 전화번호, 이메일, 주소) 수정<br> 2. 입력 사항<br> 2-1 수정할 정보 입력<br> 2-2 수정 후 변경 여부를 출력. | O      | O    |
| 게시글      | 글 등록        | 판매 글 등록       | 1. 판매글은 회원이 직접 등록 할 수 있다.<br> 1-1 판매글을 등록할 때는 제목, 내용, 가격, 카테고리를 입력받아 작성한다.<br> 1-2 관리자도 마찬가지로 판매 글을 등록 할 수 있다. | O      | O    |
|             | 관리자 공지 등록 |                    | 1. 관리자는 게시글에 공지를 작성 할 수 있다.<br> 1-1 공지글은 항상 최상단에 위치해 있다.<br> 1-2 공지글은 관리자만 작성 할 수 있다. | O      |      |
|             | 글 삭제        | 판매 글 삭제       | 1. 판매글은 언제든지 회원이 삭제 할 수 있다.<br> 1-1 판매글을 삭제 할 때는 본인이 작성한 글만 삭제가 가능하다. | O      | O    |
|             | 관리자 글 삭제   |                    | 1. 관리자는 모든 판매글과 공지글을 삭제가 가능하다.<br> 1-1 관리자는 모든 게시글에 삭제 권한을 가진다.<br> 1-2 부적합한 글과 카테고리에 맞지 않은 글을 올리면 삭제가 가능하다. | O      |      |
|             | 글 상세 보기    | 판매 글 상세 보기   | 1. 관리자와 회원은 모든 글들을 상세 보기로 하여 볼 수 있다.<br> 1-1 이때 글마다 댓글을 확인 할 수 있다. | O      | O    |
|             | 글 수정        | 판매 글 수정       | 1. 판매자는 본인 글에 한하여 판매글을 자유롭게 수정 가능하다.<br> 1-1 이때 판매중인지 판매가 완료 되었는지 예약중인지 수정도 가능하다. | O      | O    |
|             | 관리자 글 수정   |                    | 1. 관리자는 모든 글을 직접 수정 할 수 있다.<br> 1-1 이때 공지글도 수정이 자유롭게 가능하다. | O      |      |
|             | 글 검색        |                    | 1. 사용자는 글을 원하는 키워드나 카테고리로 검색을 할 수 있다.<br> 1-1 원하는 키워드를 검색하면 제목이나 내용중에 검색한 키워드를 포함한 글을 나타내준다.<br> 1-2 원하는 카테고리를 번호를 입력받으면 그 카테고리에 등록한 모든 글을 출력 한다. |        |      |
| 댓글 기능    | 댓글 등록      |                    | 1. 관리자와 회원은 원하는 판매글에 댓글을 달 수 있다.<br> 1-1 원하는 물품이 있으면 댓글을 통해 구매 예약 및 상품에 대한 글에없는 다른 정보들을 물어 볼 수 있다. | O      | O    |
|             | 댓글 삭제      |                    | 1. 회원은 본인이 달았던 댓글에 한하여 언제든지 삭제가 가능하다.<br> 1-1 이때 본인 댓글이 아닌 다른 회원의 댓글은 삭제가 불가능 하다. | O      | O    |
|             | 관리자 댓글 삭제 |                    | 1. 관리자는 모든 회원의 댓글을 언제든지 삭제가 가능하다.<br> 1-1 글 내용과 관련없는 광고성 글이나 의미없는 글 등을 관리하며 삭제를 한다. | O      |      |
|             | 댓글 수정      |                    | 1. 회원은 본인이 달았던 댓글에 한하여 언제든지 수정이 가능하다.<br> 1-1 이때 본인 댓글이 아닌 다른 회원의 댓글은 수정이 불가능 하다. | O      | O    |
|             | 관리자 댓글 수정 |                    | 1. 관리자는 모든 댓글에 수정 권한을 가진다.<br> 1-1 부적합한 언어나 단어 또는 의미없는 무지성 댓글 광고성 댓글등을 관리감독하여 언제든지 수정이 가능하다. | O      |      |
| 관심 상품    | 관심 상품 등록   |                    | 1. 사용자는 원하는 상품 글에 찜을 하여 관심 상품을 등록 할 수 있다.<br> 2. 사용자는 관심 상품을 여러개 설정 할 수 있으며 마이페이지에서 상세 확인이 가능하다. |        | O    |
|             | 관심 상품 삭제   |                    | 1. 사용자는 관심 상품을 등록을 해도 다시 관심상품을 해제 할 수 도 있다. |        |      |
|             | 관리자 관심 상품 삭제 |                | 1. 관리자는 사용자의 관심상품을 수정 할 수 있다. | O      |      |
